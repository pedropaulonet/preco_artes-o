# Preço Artesão — MVP Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Entregar a primeira versão funcional local da fase 1 de `prompt_inicial.md`.
**Architecture:** HTML estático com módulos JavaScript, CSS local e IndexedDB. Servidor apenas entrega arquivos; dados nunca são enviados ao servidor. Backup JSON validado e restauração transacional.
**Tech Stack:** HTML5, CSS, JavaScript ES modules, IndexedDB, Service Worker, testes no navegador sem dependências.
**Spec:** `prompt_inicial.md`; confirmação do usuário: servidor estático, banco local, backup JSON; sempre lembrar de fazer backup.

## Global Constraints

- Interface em português brasileiro, BRL, sem CDN, backend obrigatório ou telemetria.
- Dinheiro em centavos inteiros; divisões com BigInt e arredondamento explícito.
- Aviso permanente de backup em todas as telas; restauração pede backup recente.
- Não inventar regras fiscais: primeira fase usa custos gerenciais e simulações explicitamente identificadas.
- AGENTS.md existente deve permanecer intacto. Git indisponível neste ambiente.

## Review Focus

- Dados inválidos em JSON: rejeitar antes da transação e preservar banco existente.
- Negativos, números enormes e soma de percentuais >= 100%: rejeitar cálculo.
- Persistência indisponível: apresentar erro sem afirmar que dados foram salvos.
- Dados pessoais e nomes contendo HTML: renderizar como texto.
- Mudanças de origem/limpeza do navegador: aviso permanente e exportação acessível.
